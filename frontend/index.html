Model scope

Built for one crop. On purpose.

Every image in the training set was a tomato leaf. That narrow focus is what makes the readings below reliable — and why the model should stop at tomato's front door.

🍅

Reads accurately

Tomato leaves — healthy, diseased, or pest-damaged. Ten trained classes, listed below.

✕

Will not diagnose

Potato, pepper, or any other plant. The model will still return an answer — it just won't be a meaningful one.

Why this matters: a classifier trained only on tomato leaves has never seen a healthy potato leaf, so it can't tell "not tomato" from "diseased tomato." Feeding it other plants produces a confident-looking, unreliable guess.

What is Tomato Guard AI?

Tomato Guard AI is an artificial-intelligence based tomato leaf disease detection system designed to provide a quick preliminary assessment of tomato leaf images.

The system uses a MobileNetV2 deep-learning model trained exclusively on tomato leaf images. When a user uploads a leaf image, the system analyzes the visual patterns and returns the most likely condition along with a model confidence score.

The system is designed as an assistive screening tool for tomato growers and harvesters. It can help identify leaves that may require closer inspection, while important crop-management decisions should be confirmed with qualified agricultural guidance.
